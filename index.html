Project 1Detective

AWS CIS scanner

A read-only Python scanner that runs 20 checks from the CIS AWS Foundations Benchmark v7.1.0 against a live account and writes evidence for every resource it looks at.

  • Covers IAM, S3, CloudTrail, Config, VPC and KMS, with each check mapped to the benchmark
  • An access error is recorded as ERROR and never as a pass
  • 100 tests against a mocked AWS (moto); no real account is touched in testing
  • On my own account: 10 of 20 passing, then 13 of 20 after fixes, with one risk accepted on purpose and written down

Project 2Preventive

Terraform policy gate

A GitHub Actions gate that reads a Terraform plan for AWS and fails it if it breaks one of 12 CIS controls, before anything is built. Custom OPA/Rego rules decide; Checkov gives a second opinion.

  • 12 rules, each mapped to NIST 800-53 Rev 5, ISO 27001:2022 and SOC 2, with 75 OPA tests written test-first
  • A secure example passes 12 of 12 and an insecure example fails 12 of 12 (14 failing resources); CI checks both on every push
  • Per-resource evidence records tied to the plan's SHA-256 hash, plus JSON, Markdown and HTML reports
  • Limits are documented: root module only, plan time only
